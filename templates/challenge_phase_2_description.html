Phase 2: Text and Video Analogy Evaluation

Welcome to the second and final phase of the challenge. This phase introduces a multimodal evaluation task, where you must assess the quality of an analogy by considering both its textual description and its corresponding video animation. The goal is to evaluate the overall pedagogical effectiveness of the complete analogy package.

Task Overview

Your task in this phase is to build a system that can process textual information (the analogy and concept description) and visual information (the video animation) to predict scores for all six evaluation metrics. This is a comprehensive test of multimodal understanding.

Evaluation Metrics for Phase 2

For this phase, submissions will be evaluated on all six core metrics. This includes the three text-based metrics from Phase 1, plus three new metrics focused on the animation.

Text-Based Metrics

The following metrics from Phase 1 are still applicable:

  • Target concept coverage
  • Mapping strength
  • Metaphoricity

Video-Specific Metrics

The following three metrics are added to evaluate the animation component:

4. Alignment with the Textual Analogy

Description: How completely and accurately the animation covers the content of the analogy text.

  • 0: Poor
  • 1: Fair
  • 2: Good
  • 3: Excellent

5. Visual Clarity/Design

Description: How clearly and accurately the visual elements represent the scene described in the analogy.

  • 0: Poor
  • 1: Fair
  • 2: Good
  • 3: Excellent

6. Visual engagement

Description: Rates how effectively the animation holds the viewer’s attention and fosters interest in the topic.

  • 0: Lacks engagement
  • 1: Some moments of interest
  • 2: Generally engaging
  • 3: Consistently captivates attention

Submission Guidelines

Please provide your predictions in a submission.json file. For each example in the test set for this phase, your submission should include predictions for all six metrics.

For a complete description of the submission format and how the final leaderboard scores are calculated, please refer to the main Evaluation Details tab.
