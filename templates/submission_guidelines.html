Submission File Requirements

  • File Name: Your submission file must be named submission.json.
  • File Format: The file must be a single, valid JSON object.
  • File Size: The maximum file size is 50MB.

Content Structure

The submission.json file must contain a single JSON object. The keys of this object should be the unique example_ids provided in the test set. The value for each key should be another object containing your predicted scores for the relevant metrics of that phase.

Example for Phase 1 (Text-only)

For each example in Phase 1, you must provide predictions for the three text-based metrics.

{
  "text_example_id_001": {
    "target_concept_coverage": 2,
    "mapping_strength": 1,
    "metaphoricity": 2
  },
  "text_example_id_002": {
    "target_concept_coverage": 1,
    "mapping_strength": 2,
    "metaphoricity": 0
  }
}

Example for Phase 2 (Text + Video)

For each example in Phase 2, you must provide predictions for all six metrics.

{
  "multimodal_example_id_001": {
    "target_concept_coverage": 2,
    "mapping_strength": 2,
    "metaphoricity": 1,
    "alignment_with_text": 3,
    "visual_clarity": 2,
    "visual_engagement": 3
  },
  "multimodal_example_id_002": {
    "target_concept_coverage": 1,
    "mapping_strength": 2,
    "metaphoricity": 2,
    "alignment_with_text": 2,
    "visual_clarity": 3,
    "visual_engagement": 1
  }
}

Important: The set of keys in your submitted JSON file must exactly match the set of example_ids in the test set for the phase you are submitting to.

Submission Metadata

When you make a submission on the EvalAI platform, you will be asked to provide some metadata about your approach. This helps us understand the methods being explored. Please be prepared to provide:

  • Method Name: A short, descriptive name for your model or approach (e.g., "Multimodal Transformer with Attention").
  • Method Description: A brief description (1-2 paragraphs) of your methodology, including model architecture, features used, and training details.
  • Project URL [???] (Optional): A link to a GitHub repository, blog post, or website describing your work.
  • Publication URL [???] (Optional): A link to a paper (e.g., on arXiv) if you have written one about your method.
