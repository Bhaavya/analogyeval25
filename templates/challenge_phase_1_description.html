Phase 1: Text-only Analogy Evaluation

Welcome to the first phase of the Longform Analogy Evaluation Challenge. This phase focuses exclusively on the textual component of the analogies. The goal is to assess the quality of an analogy based solely on its written description, without considering any visual aids.

Task Overview

Your task in this phase is to develop an automated system that reads an analogy's text and its corresponding concept description, then predicts a score for each of the three text-based evaluation metrics. Your system should output these predictions in the specified JSON format.

Evaluation Metrics for Phase 1

For this phase, submissions will be evaluated on the following three core metrics:

1. Target concept coverage

Description: How well the analogy covers the topics in the provided concept description.

  • 0: Does not cover any topic.
  • 1: Covers some topics in the description.
  • 2: Covers all topics in the description.

2. Mapping strength

Description: The logical soundness and consistency of the correspondence between source and target concepts.

  • 0: Weak mapping
  • 1: Moderately strong mapping
  • 2: Very strong mapping

3. Metaphoricity

Description: The conceptual distance between the source and the target concept.

  • 0: Low
  • 1: Moderate
  • 2: High

Submission Guidelines

Please provide your predictions in a submission.json file. For each example in the test set for this phase, your submission should only include predictions for the three metrics listed above.

For a complete description of the submission format and how the final leaderboard scores are calculated, please refer to the main Evaluation Details tab.
