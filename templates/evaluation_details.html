Evaluation Details

The goal of this challenge is to create an automated system that can evaluate computer science analogies based on a set of defined metrics. Your system's predictions will be compared against a ground truth dataset of human-annotated scores using a comprehensive suite of statistical measures.

Submission Format

Your submission must be a single JSON file named submission.json. The file should contain a dictionary where keys are the unique IDs of the examples in the test set, and the values are dictionaries of your predicted scores for each metric. Please use the numerical values defined for each metric's rating scale in the sections below. 

{
  "example_id_1": {
    "target_concept_coverage": 2,
    "mapping_strength": 2,
    "metaphoricity": 1
  },
  "example_id_2": {
    "target_concept_coverage": 1,
    "mapping_strength": 2,
    "metaphoricity": 2,
    "alignment_with_text": 3,
    "visual_clarity": 2,
    "visual_engagement": 3
  },
  "...": {}
}

Leaderboard Ranking and Metrics

Your submitted automated ratings will be compared with the human-annotated ground truth ratings using the following statistics. These will be displayed on the leaderboard for each of the core analogy metrics (e.g., Target Concept Coverage, Mapping Strength, etc.).

Kendall's tau-b: Compares the rank order of your automated evaluation with the human ratings. It is a measure of rank correlation. Higher is better.

Core Analogy Metrics Being Evaluated

The challenge is divided into two phases. The evaluation statistics described above will be applied to the following core analogy metrics in each phase.

Phase 1: Text-only Analogy Evaluation

This phase evaluates analogies based only on their textual description.

1. Target concept coverage

Description: How well the analogy covers the topics in the provided concept description.

  • 0: Does not cover any topic.
  • 1: Covers some topics in the description.
  • 2: Covers all topics in the description.

2. Mapping strength

Description: The logical soundness and consistency of the correspondence between source and target concepts.

  • 0: Weak mapping
  • 1: Moderately strong mapping
  • 2: Very strong mapping

3. Metaphoricity

Description: The conceptual distance between the source and the target concept.

  • 0: Low
  • 1: Moderate
  • 2: High

Phase 2: Text and Video Analogy Evaluation

This phase includes the three metrics from Phase 1, plus three additional metrics focused on the visual animation.

4. Alignment with the Textual Analogy

Description: How completely and accurately the animation covers the content of the analogy text.

  • 0: Poor
  • 1: Fair
  • 2: Good
  • 3: Excellent

5. Visual Clarity/Design

Description: How clearly and accurately the visual elements represent the scene described in the analogy.

  • 0: Poor
  • 1: Fair
  • 2: Good
  • 3: Excellent

6. Visual engagement

Description: Rates how effectively the animation holds the viewer’s attention and fosters interest in the topic.

  • 0: Lacks engagement
  • 1: Some moments of interest
  • 2: Generally engaging
  • 3: Consistently captivates attention
